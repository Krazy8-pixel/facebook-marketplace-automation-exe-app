# Facebook Marketplace Automation EXE App

Windows desktop installer and signed update downloads.

## Install

Download the latest **FacebookMarketplaceAutomation-Setup-VERSION.exe** from [Releases](https://github.com/Krazy8-pixel/facebook-marketplace-automation-exe-app/releases/latest) and run it. Setup includes the automation browser and prepares the desktop runtime. Internet access is required during setup and Facebook automation.

## Update

When notified of a new version, finish running automation, open **Settings**, select **Check for Updates**, then **Download & Install**. Ordinary updates retain saved accounts, sessions, groups, listings, and media. A release that intentionally resets saved listings asks before installation.

## Background tasks

Close the window to keep the app in its system tray. It imports listings every 24 hours and refreshes clicks every 4 hours. The PC must be powered on, awake, and connected. Overdue maintenance runs once when the app resumes. Use the tray menu to exit completely.

This repository contains release files only. Client databases, credentials, sessions, and source code are not included.
